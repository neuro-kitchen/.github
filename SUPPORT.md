# Getting help

- **Questions about using a tool:** open an issue in that project's repository and describe what you're trying to do.
- **Bugs:** use the bug report template, and include your OS, version, and the steps to reproduce.
- **Security problems:** see [SECURITY.md](SECURITY.md). Please don't post them publicly.

neuro-kitchen is maintained by one person, so replies are best-effort. Clear, reproducible reports get answered fastest.
